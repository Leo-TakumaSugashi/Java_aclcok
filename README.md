# *** ⏰ TS_AnalogClock ***  
A lightweight analog clock with a transparent background, built using JavaFX.
It floats beautifully on your desktop with smooth hand movements and minimalist design.

# 🧪 Overview
- Analog clock built with JavaFX
- Transparent background with no window border
- Hour, minute, and second hands
- Roman numerals (III, VI, IX, XII) and tick marks
- Draggable window

# 🚀 Usage
## 📦 Prerequisites (only once)  
* on macOS *    
```bash brew install jbang  ```
* or for all platforms * 
```bash  curl -Ls https://sh.jbang.dev | bash ```

# ▶ Run the clock
``` bash jbang TS_AnalogClock.java & ```  
Add & to run in the background (on Linux/macOS)
On Windows, just run it normally
